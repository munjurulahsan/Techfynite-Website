# TechFynite - Full Website Clone

This project is a 1:1 identical, fully functional clone of the official [TechFynite](https://www.techfynite.com/) website.

## 🚀 How to Run Locally

You can run the site using any local HTTP server:

```bash
# Using Python
python3 -m http.server 8000

# Or using npx serve
npx serve .
```

Open your browser and navigate to:
👉 **`http://localhost:8000/`**
